# Frozen Social Frontier Control

This directory contains the original matcher source snapshot used for historical Social frontier benchmark comparisons. The 14 source files and `source-manifest.json` are copied byte-for-byte from the checksum-manifested control snapshot; the manifest records each source SHA-256 and the original engine hash.

These files are benchmark/test fixtures only. They preserve old behavior for comparison and must never be used by production matchmaking. Generated benchmark runs and raw reports remain under the ignored `benchmarks/generated/` directory.
