# Enamel achievement pins

Approved artwork families: Back in Business (three evolving birds), Mix It Up (three evolving knots), and First Serve (one shooting-star milestone).

Produced with the built-in image generation tool from the approved concept boards. Extraction prompt: isolate the specified pin, preserve its approved silhouette, enamel colors and metal outlines, remove labels and other pins, center on a square canvas. Transparent backgrounds were requested. The two bronze exports needed a final plain-white background replacement; the shared component uses multiply blending against the app's light surfaces. All other exports retain their alpha channel.

Files are named by achievement ID and tier; First Serve has no tier suffix. Next Image serves appropriately sized optimized versions. The original source exports remain in the generated-images archive.

The shared BadgeIcon component selects the earned tier. Locked collection badges use a muted first-tier image. Detail rows show each tier's artwork in color alongside its explicit earned/locked text. Achievement calculations and unlock rules are unchanged.
