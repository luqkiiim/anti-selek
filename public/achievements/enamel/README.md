# Enamel achievement pins

The collection has artwork for every club achievement. First Serve is a single milestone; the other ten achievements have bronze, silver, and gold variants.

The original PNG families are Back in Business (three evolving birds), Mix It Up (three evolving knots), and First Serve (one shooting-star milestone). They were produced with the built-in image generation tool from approved concept boards. The two original bronze exports have plain-white backgrounds, so the shared component uses multiply blending against the app's light surfaces.

A Familiar Face and Finding Your Rhythm are additional transparent PNG families. Those six variants are stored at 640 × 640 pixels for the app's 72–96 pixel badge displays.

On the Board, Down to the Wire, Clean Sweep, Raising the Bar, Good Together, and Making It Happen use original SVG artwork generated by `node scripts/generate-achievement-enamel-svg.mjs`. Their motifs use badminton shuttlecocks and rackets or sport-neutral symbols. The source script keeps the tier palettes, metal rims, and sizes consistent across these families.

Files are named by achievement ID and tier; First Serve has no tier suffix. The shared `BadgeIcon` component selects the earned tier and the file format. Locked collection badges use a muted first-tier image. Detail rows show each tier's artwork in color alongside its explicit earned/locked text. Achievement calculations and unlock rules are unchanged.
